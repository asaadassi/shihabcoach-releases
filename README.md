# Shihab Coach — الإصدارات

حمّل أحدث نسخة من صفحة [الإصدارات](https://github.com/asaadassi/shihabcoach-releases/releases/latest):

- `ShihabCoach-Setup-x.y.z.exe`: برنامج ويندوز لأدوات الشرح على الشاشة أثناء البث أو الاجتماع أو التسجيل.

البرنامج المثبّت يتحقق من هذه الصفحة بنفسه ويعرض التحديثات الجديدة. كل ملف يرافقه ملف توقيع `.sig` وملف بصمات `SHA256SUMS.txt`، ولا يقبل البرنامج تحديثًا بلا توقيع صحيح.

---

Shihab Coach releases. Download the latest version from the [Releases](https://github.com/asaadassi/shihabcoach-releases/releases/latest) page. The installed app checks this page itself; every file comes with a `.sig` signature and `SHA256SUMS.txt`, and unsigned updates are refused.

This repository holds releases only; the source code is private.
